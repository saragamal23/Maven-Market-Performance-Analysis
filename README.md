# Maven Market Performance Analysis

## 📊 Project Overview

This project analyzes Maven Market's sales performance across the USA, Mexico, and Canada using Power BI.

The goal is to transform raw transaction data into an interactive dashboard that helps understand sales performance, customer behavior, product performance, returns, and store performance.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## 🧹 Data Preparation

The data was prepared using Power Query, including:

- Combining 1997 and 1998 transaction data using Append.
- Cleaning and transforming customer data.
- Creating customer attributes such as Full Name, Birth Year, Age, and Age Category.
- Creating and transforming the Calendar table.
- Preparing Products, Stores, Regions, and Returns tables.
- Building relationships between the tables.

## 🔗 Data Model

The project uses a relational data model connecting:

- Customers
- Products
- Transactions
- Returns
- Stores
- Regions
- Calendar

The model was designed to support accurate calculations and interactive analysis.

## 📐 DAX Measures

Several DAX measures were created to analyze business performance, including:

- Total Transactions
- Quantity Sold
- Quantity Returned
- Return Rate
- Total Revenue
- Monthly Revenue Target
- Last Month Revenue
- Last Month Transactions

## 📊 Dashboard

The final Power BI dashboard provides an overview of:

- Sales Performance
- Revenue
- Profit
- Transactions
- Returns
- Product Performance
- Store and Regional Performance
- Monthly Trends

## 💡 Key Business Insights

The dashboard helps identify:

- Sales and revenue performance over time.
- Differences in performance across regions and stores.
- Product categories and products contributing to sales.
- Return rate and returned quantities.
- Monthly performance compared with targets.

## 🎯 Project Objective

This project demonstrates the complete data analysis workflow:

**Data Cleaning → Data Transformation → Data Modeling → DAX → Data Visualization → Business Insights**
